# PARANOISE GuildBattle

パラノイズのギルド戦データベース／勝敗予測PWAの開発リポジトリです。

## Phase 1

- 自軍：1ギルド、25人、1人2パーティー（50PT）
- 敵軍：最大16ギルド、各25人、1人2パーティー（最大800PT）
- 合計最大850PTをIndexedDBで管理
- メンバー名、PT1/PT2、6キャラクター配置、総戦力、HP、疲労度、疲労補正倍率、戦闘数を保存
- JSONバックアップ／復元
- スクリーンショット保存基盤
- PWA／オフラインキャッシュ

## 戦闘ルール v1.0

- 攻撃側初期TU：0
- 防衛側初期TU：50
- オート戦闘
- 勝利した部隊はHP回復後に次戦へ進む
- 勝利部隊には疲労度が蓄積し、疲労度に比例してステータスが弱体化
- 引き分けは防衛側の勝利
- 疲労による具体的な減衰率は、正式な数値が確認できるまで未確定パラメータとして扱う

## Phase 2

キャラクターマスターDBをIndexedDBに本格実装。

- キャラクター固有IDを付与（例：`CHR-0001`）
- キャラクター名、レアリティ、属性を管理
- 基礎HP／攻撃／防御／速度を管理
- スキル／効果、状態異常／TU等の情報欄を管理
- キャラクターの新規登録・編集・削除
- 使用中キャラクターの誤削除を防止
- 各PTの6枠をキャラクター名の自由入力から、キャラクターIDを参照する選択式へ変更
- 配置1～6を保持し、将来の戦闘シミュレーションで利用可能
- DBバージョンを2へ更新し、Phase 1データを維持したまま移行
- JSONバックアップのschema_versionを2へ更新
