# PARANOISE GuildBattle

パラノイズのギルド戦データベース／勝敗予測PWAの開発リポジトリです。

## Phase 1

- 自軍：1ギルド、25人、1人2パーティー（50PT）
- 敵軍：最大16ギルド、各25人、1人2パーティー（最大800PT）
- 合計最大850PTをIndexedDBで管理
- メンバー名、PT1/PT2、6キャラクター配置、総戦力、HP、疲労度、疲労補正倍率、戦闘数を保存
- JSONバックアップ／復元
- PWA／オフラインキャッシュ

## 戦闘ルール v1.0

- 攻撃側初期TU：0
- 防衛側初期TU：50
- オート戦闘
- 勝利した部隊はHP回復後に次戦へ進む
- 勝利部隊には疲労度が蓄積し、疲労度に比例してステータスが弱体化
- 引き分けは防衛側の勝利
- 疲労による具体的な減衰率は、正式な数値が確認できるまで未確定パラメータとして扱う

## Phase 2

キャラクターマスターDBをIndexedDBに実装。

- キャラクター固有ID（例：`CHR-0001`）
- キャラクター名、レアリティ、属性
- 基礎HP／攻撃／防御／速度
- スキル／効果、状態異常／TU等
- 新規登録・編集
- 各PTの6枠をキャラクターID参照で管理
- 配置1～6を保持

## Phase 3：スクリーンショット自動登録

**実装済み。**

処理フロー：

`スクショ選択 → OCR（日本語+英語）→ OCR文字列をキャラクター名と照合 → キャラクターID特定 → 6枠の確認 → 指定PTへ保存`

### 実装内容

- ブラウザ上でTesseract.jsを使用
- 日本語・英語OCR
- キャラクターDBの名前との正規化・類似度照合
- キャラクターIDを自動特定
- 最大6枠の候補を自動生成
- OCR結果・候補・類似度を表示
- 低信頼候補はユーザーがキャラクターIDを選び直せる
- 指定した自軍／敵ギルド・メンバー・PTへ反映
- `partyCharacters.source = screenshot_ocr` として取得元を記録
- スクショの解析履歴を`screenshots`へ保存
- OCR生テキストを確認可能

### 重要な制約

現在のPhase 3は**スクショ内のキャラクター名をOCRで認識する方式**です。キャラクターの立ち絵・アイコンだけから画像そのものを識別する画像分類はまだ実装していません。そのため、キャラクターDBへ正確な名称が登録されていることが前提です。

また、ブラウザ上のOCRはスクショの解像度・文字サイズ・背景・フォント等により認識率が変わります。自動反映前に6枠を確認できる構成にしています。
